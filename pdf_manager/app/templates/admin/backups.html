Konfiguracja automatycznych backupów

Aby uruchamiać backup automatycznie, dodaj zadanie cron:

# Edytuj crontab
crontab -e

# Dodaj linię (backup codziennie o 2:00):
0 2 * * * cd /ścieżka/do/projektu && /ścieżka/do/venv/bin/python backup.py >> backups/backup.log 2>&1

Backupy zawierają bazę danych (app.db) oraz wszystkie pliki z folderu uploads/.
